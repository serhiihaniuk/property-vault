# Archived Task Records

This folder contains completed task files that were moved out of the live
startup path after the main implementation backlog finished.

Use these files only when you need historical execution context, for example:

- checking what was actually merged during a completed task
- tracing a past coordinator/reviewer decision
- understanding why a follow-up task was created

Do not treat this folder as part of the default startup path.

Live or future task files belong in:

- `docs/implementation/tasks/`
