# Active Task Files

This folder is the live task surface for future work.

Rules:

- put only active or future task files here
- treat this folder as part of the default startup path
- do not keep completed task records here once they stop helping live work

Completed task records are archived under:

- `docs/implementation/archive/tasks/`

Those archived files are historical reference only. Future agents should not
load them by default unless a live task or the user explicitly asks for
historical context.
