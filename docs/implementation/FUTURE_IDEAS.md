# Future Product Ideas

These are intentionally not part of the active implementation backlog yet.
They are product ideas worth revisiting later once the main app foundation and
core vertical slices are stable.

## Meter reading entry and advance comparison

- Allow manual entry of real meter readings.
- Estimate actual consumption for the selected period.
- Compare actual consumption with the monthly advance/prepayment currently paid.
- Show whether the current monthly advance looks too low, too high, or roughly
  aligned with real usage.
- Use this to help explain likely settlement drift before the yearly
  reconciliation arrives.

Short original intent: let the user enter real meter readings and compare real
consumption with the monthly advance currently being paid.
